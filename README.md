# humanizer

Skill that removes signs of AI-generated writing from German and English text.
See [SKILL.md](SKILL.md) for the pattern inventory, budgets and context profiles.

Based on [blader/humanizer](https://github.com/blader/humanizer) (MIT, Siqi Chen)
and Wikipedia's "Signs of AI writing" guide.

## Install

```bash
ln -s ~/work/mf/humanizer ~/.soma/skills/humanizer
```
